# 콘텐츠 실시간 자동 업데이트 및 앱 버전 관리 가이드 (한국어)

## 1. 개요
`MeatGuideOverlay` 시스템은 **무중단 실시간 콘텐츠 업데이트(OTA)** 와 **바이너리 앱 자체 업데이트(APK)** 의 두 계층으로 완벽히 분리되어 운영됩니다.

---

## 2. 계층별 업데이트 방식 비교

| 구분 | 실시간 콘텐츠 업데이트 (OTA) | 앱 프로그램 자체 업데이트 (APK) |
| :--- | :--- | :--- |
| **대상 항목** | 캐릭터/말풍선 문구, 돼지고기 특수부위 목록, 설명/맛/식감/추천 팁, 소생갈비살 정보, 키오스크 오류 감지 문구, 재부팅 가이드, 팝업 무터치 자동 닫힘 시간 | 신규 안드로이드 API 대응, 새로운 시스템 권한 추가, 코어 서비스/접근성 로직 수정 |
| **적용 시점** | 관리자 웹에서 `[태블릿에 게시]` 클릭 즉시 | 신규 APK 파일 직접 설치 시 |
| **앱 재설치 필요 여부** | **불필요 (앱 재시작도 불필요)** | **필요 (기존 앱 위에 업데이트 설치)** |
| **오프라인 동작** | 네트워크 단절 시에도 마지막 정상 버전 유지 | 오프라인에서도 기설치 앱 정상 동작 |
| **안전 장치** | 스키마 버전 검증, 원자적(Atomic) 임시 파일 교체, 손상된 JSON 자동 거부 | 서명 키(Keystore) 일치 검증 |

---

## 3. 실시간 콘텐츠 업데이트 상세 동작 원리

```text
[관리자 웹 콘솔] ───(게시)───> [Cloud Firestore (published/current)]
                                      │
               ┌──────────────────────┴──────────────────────┐
               ▼ (실시간 리스너 수신)                        ▼ (WorkManager 주기 확인)
      [MeatGuideOverlay Foreground Service]           [ContentSyncWorker]
               │                                             │
               └──────────────────────┬──────────────────────┘
                                      ▼
                        [ContentRepository.isValid() 검증]
                                      │ (통과 시)
                                      ▼
                   [Atomic File Cache 원자적 교체 (.tmp -> .json)]
                                      │
                                      ▼
                       [화면 실시간 반영 (UI StateFlow)]
```

### 3.1 원자적(Atomic) 파일 교체 원리
1. 새로 수신된 Firestore 스키마(`schemaVersion`, `contentVersion`, `beefRibItem` 소생갈비살 단일 제약 등)를 엄격히 검증합니다.
2. 다운로드 데이터를 `content.json.tmp` 임시 파일에 완전히 기록하고 버퍼를 flush합니다.
3. 임시 파일이 온전하게 디스크에 저장된 후에만 기존 `content.json`을 원자적으로 교체(renameTo)합니다.
4. 네트워크가 중간에 끊기거나 비정상 데이터가 유입되더라도 기존의 정상 콘텐츠 파일이 100% 보존됩니다.

---

## 4. 앱 프로그램 자체 업데이트 (APK Update)

새로운 APK 버전이 배포된 경우:
1. 관리자 대시보드에서 각 태블릿의 앱 버전 정보를 확인합니다.
2. 직원이 태블릿의 `직원용 관리 대시보드` 화면에서 `앱 버전 확인`을 누릅니다.
3. 신규 APK 다운로드 링크 및 SHA-256 해시를 확인한 뒤 안드로이드 표준 패키지 설치 화면을 통해 업데이트합니다.
4. 본 앱은 권한 없는 무단 자동 백그라운드 설치나 시스템 보안 우회를 일체 수행하지 않습니다.
