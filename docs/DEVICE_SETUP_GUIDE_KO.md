# 태블릿 최초 권한 설정 및 운영 가이드 (한국어)

## 1. 개요
`MeatGuideOverlay` 앱을 설치한 뒤, 오버레이 표시와 오류 감지가 동작하도록 권한을 한 번 허용해야 합니다.

---

## 2. 최초 설정 마법사

앱을 처음 실행하면 **최초 설정 마법사**가 열립니다. 설정을 마친 뒤에는 앱 아이콘을 누르면 **직원용 관리 대시보드**가 열리고, 대시보드의 **[설정 마법사 다시 열기]**로 언제든 다시 들어올 수 있습니다.

### 2.1 [1] 다른 앱 위에 표시 권한 (필수)
* **목적**: 키오스크 화면 위에 캐릭터와 포스터 팝업을 띄웁니다.
* **설정 방법**: `[권한 설정 열기]`를 누른 뒤 `고기 부위 안내`를 `허용(ON)`으로 바꿉니다.

### 2.2 [2] 접근성 오류 감지 서비스 권한
* **목적**: 키오스크 앱의 "서버에 접속이 끊겼습니다" 같은 팝업을 감지해 직원 안내창을 띄우고, 안내창에서 전원 메뉴를 열 수 있게 합니다.
* **설정 방법**: `[접근성 설정 열기]` → `설치된 서비스` → `고기 부위 안내`를 켭니다.

### 2.3 [3] 감시할 키오스크 앱 선택
* 목록에서 **매장의 실제 주문 키오스크 앱**을 선택합니다. 기본 선택은 `가상 테스트 키오스크`이므로 반드시 바꿔 주세요.
* 선택한 키오스크 앱만 감시하며 다른 앱은 감시하지 않습니다.

### 2.4 [4] 기기 식별 및 동작 옵션
* **태블릿 이름**: 관리자 웹에 표시될 이름(예: `테이블-01`)을 입력합니다.
* **태블릿 부팅 시 선택한 키오스크 앱도 자동 실행**: 필요할 때만 체크합니다.

### 2.5 완료
* `[설정 저장 및 시작]`을 누르면 서비스가 시작되고 화면 **좌측 상단**에 캐릭터와 말풍선이 나타납니다.

### 2.6 (선택) 시스템 설정 변경 권한
* 앱은 영업 중 화면이 꺼지지 않도록 화면 자동 꺼짐을 끄려고 시도합니다. 이 동작은 `설정` → `애플리케이션` → `고기 부위 안내` → `시스템 설정 변경`을 허용한 경우에만 적용됩니다.
* 허용하지 않으면 태블릿의 안드로이드 화면 설정을 그대로 따릅니다. 영업 종료 후에는 직원이 화면을 직접 끕니다.

---

## 3. 캐릭터 조작
* **위치**: 캐릭터는 좌측 상단에 고정됩니다. 끌어서 옮겨도 손을 떼면 좌측 상단으로 돌아갑니다.
* **말풍선**: 3초마다 한국어 → 영어 → 일본어로 바뀝니다. 문구는 관리자 웹에서 수정합니다.
* **포스터 열기**: 캐릭터나 말풍선을 누르면 전체 화면 포스터가 열립니다. 상단 탭으로 한글/English/日本語를 바꾸고, 두 손가락으로 1~5배 확대할 수 있습니다.
* **닫기**: `닫기` 버튼을 누르거나, 설정된 시간(기본 5분) 동안 터치가 없으면 자동으로 닫힙니다.
