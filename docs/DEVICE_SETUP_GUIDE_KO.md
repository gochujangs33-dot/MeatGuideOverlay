# 태블릿 최초 권한 설정 및 운영 가이드 (한국어)

## 1. 개요
`MeatGuideOverlay` 앱을 설치한 후, 태블릿에서 정상적으로 화면 상단 오버레이 표시 및 오류 감지가 동작하도록 권한을 1회 승인해야 합니다.

---

## 2. 최초 실행 설정 마법사 단계

앱을 실행하면 자동으로 **최초 설정 마법사 (`SetupWizardActivity`)** 가 열립니다.

### 2.1 [1단계] 다른 앱 위에 표시 권한 (필수)
* **목적**: 기존 키오스크 화면 위에 캐릭터와 고기 가이드 팝업을 띄우기 위해 필요합니다.
* **설정 방법**: `[권한 설정 열기]` 버튼을 누른 뒤, 목록에서 `고기 부위 안내`를 찾아 토글 스위치를 `허용(ON)`으로 변경합니다.

### 2.2 [2단계] 접근성 서비스 권한 (오류 감지용)
* **목적**: 키오스크 앱에서 "서버에 접속이 끊겼습니다" 등의 네트워크 연결 단절 팝업 발생 시 직원에게 재부팅 안내를 제공합니다.
* **설정 방법**: `[접근성 설정 열기]` 버튼을 누르고, `설치된 서비스` -> `고기 부위 안내`를 선택하여 활성화합니다.

### 2.3 [3단계] 감시할 키오스크 앱 선택
* 태블릿에 설치된 앱 목록 드롭다운에서 **매장의 실제 주문 키오스크 앱** (또는 테스트 시 `가상 테스트 키오스크 (com.antigravity.testkiosk)`)을 선택합니다.
* **성능 보호 원칙**: 본 보조 앱은 선택된 키오스크 패키지만 엄격히 감시하며, 기타 앱은 일체 감시하지 않습니다.

### 2.4 [4단계] 기기 이름 및 옵션
* **태블릿 식별명**: 관리자 웹 대시보드에 표시될 기기 이름(예: `테이블-01`, `테이블-02`)을 입력합니다.
* **부팅 시 키오스크 자동 실행**: 필요 시 체크합니다. (기존 키오스크가 자체 자동 시작하는 경우 해제 유지)

### 2.5 [5단계] 완료
* `[설정 완료 및 시작]` 버튼을 누르면 즉시 포그라운드 서비스가 시작되고 화면 우측 가장자리에 귀여운 캐릭터와 말풍선이 나타납니다.

---

## 3. 캐릭터 조작 방법
* **드래그 이동**: 캐릭터를 손가락으로 원하는 상/하 위치로 자유롭게 드래그할 수 있습니다. 손을 떼면 가장 가까운 좌/우 가장자리에 자동으로 깔끔하게 스냅됩니다.
* **위치 영구 저장**: 직원이 이동해 둔 캐릭터 위치는 태블릿을 재부팅해도 그대로 유지됩니다.
* **탭하여 설명 열기**: 캐릭터 또는 말풍선을 터치하면 즉시 반투명 배경의 `고기 부위 가이드` 모달창이 나타납니다.
* **자동 닫기**: 고객이 설명을 보다가 60초간 추가 터치가 없으면 자동으로 닫혀 원래 주문 화면으로 복귀합니다.
