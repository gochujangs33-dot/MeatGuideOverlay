# 보안 및 개인정보 보호

## 1. 개인정보 및 주문 데이터
`MeatGuideOverlay`는 다음을 하지 않습니다.
* **주문·결제 데이터 수집**: 메뉴 선택, 수량, 결제 금액을 읽거나 저장하지 않습니다.
* **결제 장치 접근**: 카드·NFC 리더와 통신하지 않습니다.
* **화면 캡처·키 입력 기록**: `MediaProjection`이나 키로깅을 쓰지 않습니다. 접근성 서비스는 선택한 키오스크 앱 화면에 등록된 오류 문구가 있는지만 확인합니다.
* **키오스크 자동 조작**: 키오스크 버튼을 누르지 않습니다. 접근성 서비스의 전역 동작은 직원이 안내창에서 [전원 메뉴 열기]를 누를 때 시스템 전원 메뉴를 여는 용도로만 씁니다.

## 2. 인증과 권한 (운영자 결정: 비밀번호 없는 관리자 웹)

관리자 웹과 태블릿 모두 Firebase **익명 로그인**을 씁니다. 매장 운영 편의를 위해 관리자 웹에 비밀번호를 두지 않기로 결정했습니다(2026-09-27).

현재 규칙(`firebase/firestore.rules`, `firebase/storage.rules`)에서 로그인된 세션은 누구나 다음을 할 수 있습니다.

| 대상 | 권한 |
| :--- | :--- |
| `active_popup/*` (포스터 주소, 말풍선, 태블릿 설정) | 읽기·쓰기 |
| `devices/*` (모든 태블릿 상태) | 읽기 (쓰기는 자기 문서만) |
| Storage `popups/**`, `assets/**` | 읽기, 25MB 이하 이미지 업로드 |
| `drafts`, `admins`, `content_history` | 접근 불가 (등록된 관리자 전용) |

> [!WARNING]
> **관리자 주소를 숨기는 것만으로는 보호되지 않습니다.** 관리자 웹 코드에 Firebase 설정값이 들어 있고, 주소가 프로젝트 이름과 같은 기본 도메인이라 짐작하기 쉽습니다. 이 값을 가진 사람은 관리자 화면을 거치지 않고도 매장 태블릿에 표시되는 포스터와 문구를 바꿀 수 있습니다.
>
> 이상한 포스터가 보이면 관리자 웹에서 올바른 포스터를 다시 적용하세요. 나중에 막아야 할 때는 관리자 전용 로그인(구글 계정 등)으로 쓰기 권한을 제한하거나 Firebase App Check를 적용합니다.

관리자 웹의 말풍선 자동 번역은 입력한 한국어 문구를 Google 번역 서버(`translate.googleapis.com`)로 보냅니다.

## 3. 서명 키와 비밀정보
* **Git에서 제외**(`.gitignore`): `local-signing/`(릴리즈 키스토어), `keystore.properties`, `google-services.json`, `.env`, `.env.local`, 모든 APK.
* **서명 비밀번호**: `scripts/generate-keystore.ps1`이 `local-signing/PRIVATE_SIGNING_INFO.txt`와 `keystore.properties`에 **평문으로** 저장합니다. 암호화되어 있지 않으므로 이 폴더를 백업할 때 외부에 공유하지 마세요. 키스토어를 잃으면 설치된 앱을 업데이트할 수 없습니다.
* Firebase 웹/Android API 키는 비밀값이 아니며, 접근 제어는 보안 규칙이 담당합니다.
