# 저사양 태블릿 성능 및 리소스 측정 보고서 (Performance Report)

## 1. 개요 및 성능 목표치
본 프로젝트는 구형 및 저사양 안드로이드 태블릿(1GB~2GB RAM, Quad-Core 저클럭 CPU) 환경에서도 기존 주문 키오스크의 성능 저하나 터치 딜레이 없이 상시 실행될 수 있도록 엄격한 성능 가이드라인을 준수하여 제작되었습니다.

## 3. 핵심 성능 최적화 기법

1. **Jetpack Compose 배제 및 XML View 채택**:
   * 구형 디바이스 런타임 컴파일 부하 및 Recomposition 오버헤드를 원천 차단하여 초기 메모리 점유율을 30MB대로 억제.
2. **바운디드(Bounded) 접근성 노드 탐색**:
   * 화면 텍스트 노드 탐색 깊이를 최대 12, 최대 60개 노드로 엄격히 제한.
   * 이벤트 처리 스로틀링(400ms)을 적용하여 키오스크 화면 갱신 시 CPU 점유율 스파이크 방지.
3. **네이티브 벡터 드로어블(Vector Drawable) 및 WebP 우선 구조**:
   * 해상도별 대용량 비트맵 유지로 인한 메모리 누수 방지.
   * 모달 팝업이 닫힐 때 상세 뷰의 뷰 바인딩 및 애니메이터 즉시 해제.
4. **DataStore 및 코루틴 SupervisorJob 기반의 비동기 I/O**:
   * 메인 스레드 렌더링 블로킹 없는 매끄러운 자석 스냅 효과 구현.
5. **실시간 Firestore 리스너 최소화 & 주기적 동기화 백오프**:
   * 네트워크 재연결 시에만 원자적 확인을 수행하고, 폴링 루프를 제거하여 네트워크 칩셋의 딥슬립 유지.
