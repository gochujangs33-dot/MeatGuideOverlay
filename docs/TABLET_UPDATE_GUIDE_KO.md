# 태블릿 식별 및 업데이트 관리 안내

## 1. 태블릿 번호 확인 방법

태블릿의 `8207G2305849` 같은 값은 Android 기기 시리얼 번호이며 테이블 번호가 아닙니다.

실제 관리 화면에 표시되는 번호는 최초 설정 마법사의 **기기 식별명**입니다.

예시:

- `테이블-01`
- `테이블-02`
- `테이블-03`

번호를 바꾸려면 태블릿에서 직원용 관리 대시보드의 **설정 마법사 다시 열기**를 누르고 기기 식별명을 저장합니다.

## 2. 관리자 페이지에서 확인할 수 있는 항목

관리자 페이지([https://meatguideoverlay.web.app](https://meatguideoverlay.web.app))의 **연결된 태블릿 현황**에서 다음 정보를 확인합니다.

- 테이블 번호 또는 기기 이름
- 설치된 앱 버전
- 현재 콘텐츠 버전
- 온라인/오프라인 상태
- 태블릿 모델과 Android 버전
- 마지막 상태 보고 시간
- 최신 앱인지 여부 또는 업데이트 필요 여부

상태 보고는 앱이 실행되고 인터넷에 연결되어 있을 때 자동으로 이루어집니다. 마지막 보고가 10분을 넘으면 오프라인으로 표시됩니다.

## 3. 업데이트 여부 확인

관리자 페이지의 태블릿 현황에서 `최신 앱` 또는 `업데이트 필요` 상태를 확인합니다.

태블릿 자체에서는 직원용 관리 대시보드의 **앱 업데이트 확인** 버튼을 누릅니다.

1. 새 버전 확인
2. 업데이트 내용 확인
3. `다운로드 및 설치` 선택
4. Android 설치 화면에서 업데이트 승인

처음 한 번은 설정에서 이 앱의 **알 수 없는 앱 설치 허용**을 켜야 할 수 있습니다.

## 4. 콘텐츠 설정과 앱 코드의 차이

Firebase로 즉시 반영되는 항목:

- 팝업 이미지
- 말풍선 문구
- 팝업 무터치 자동 닫힘 시간
- 캐릭터 위치
- 화면 절전 및 자동 재부팅 설정

APK 업데이트가 필요한 항목:

- 새로운 Android 기능
- 권한 및 서비스 동작 변경
- 앱 화면 변경
- 앱 충돌 및 오버레이 로직 수정

팝업 자동 닫힘 시간은 현재 기본 5분이며 관리자 페이지에서 분 단위로 변경할 수 있습니다. `0분`은 자동 닫힘을 사용하지 않습니다.

## 5. 현재 확인된 예시

현재 연결된 태블릿은 다음과 같이 Firebase에 보고되고 있습니다.

- 기기 이름: `테이블-03`
- 앱 버전: `1.0.16`
- 콘텐츠 버전: `v3`
