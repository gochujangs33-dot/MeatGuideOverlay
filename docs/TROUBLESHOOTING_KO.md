# 문제 해결 및 트러블슈팅 가이드 (한국어)

## 1. 캐릭터가 화면에 나타나지 않는 경우

### 증상
앱을 설치하고 실행했으나 화면 가장자리에 캐릭터와 말풍선이 보이지 않음.

### 원인 및 해결 방법
1. **다른 앱 위에 표시 권한 미허용**:
   * 태블릿의 `설정` -> `애플리케이션` -> `특별한 접근권한` -> `다른 앱 위에 표시`로 이동하여 `고기 부위 안내`가 활성화되어 있는지 확인합니다.
2. **직원용 대시보드에서 수동 표시 실행**:
   * `MeatGuideOverlay` 앱을 열어 `직원용 관리 대시보드`에서 `[캐릭터 화면에 다시 표시]` 버튼을 터치합니다.
3. **포그라운드 서비스 알림 확인**:
   * 상단 알림 바에 "고기 부위 안내가 실행 중입니다." 상주 알림이 떠 있는지 확인합니다.

## 2. 키오스크 서버 연결 끊김 오류 감지가 되지 않는 경우

### 증상
키오스크 화면에 "서버에 접속이 끊겼습니다" 팝업이 떴으나 보조 앱의 재부팅 안내창이 나타나지 않음.

### 원인 및 해결 방법
1. **접근성 서비스 비활성화**:
   * `설정` -> `접근성` -> `설치된 앱(서비스)` -> `고기 부위 안내`가 켜져 있는지 확인합니다.
2. **감시 패키지 불일치**:
   * 본 보조 앱은 오탐 방지와 태블릿 성능 보호를 위해 **지정된 키오스크 패키지만 감시**합니다.
   * `설정 마법사`를 다시 열어 실제 매장 키오스크의 패키지명이 정확히 선택되었는지 확인합니다.
3. **5분 쿨다운 활성화 상태**:
   * 동일한 오류 문구가 계속 화면에 떠 있을 때 반복해서 팝업이 뜨는 것을 막기 위해 기본 5분 쿨다운이 적용되어 있습니다. 쿨다운이 지나면 정상 감지됩니다.
4. **오류 문구 차이**:
   * 키오스크 제조사마다 오류 문구가 다를 수 있습니다 (예: `서버 연결 실패`, `네트워크 통신 오류` 등). 관리자 웹의 `오류 감지 설정`에서 해당 매장의 정확한 문구를 추가해 주세요.

## 3. 태블릿 재부팅 후 자동 실행이 되지 않는 경우

### 증상
태블릿 전원을 껐다 켰을 때 보조 앱이 자동으로 시작되지 않음.

### 제조사별 해결 방법
* **삼성 갤럭시 탭**: `설정` -> `배터리 및 디바이스 케어` -> `배터리` -> `백그라운드 사용 제한` -> `절전 예외 앱`에 `고기 부위 안내`를 추가합니다.
* **레노버(Lenovo) 태블릿**: `설정` -> `앱 관리` -> `자동 시작 관리자(Auto-start)`에서 `고기 부위 안내`를 허용합니다.
* **샤오미/기타 중국 제조사**: `보안 앱` -> `자동 시작 권한` 및 `배터리 세이버 - 제한 없음`으로 설정합니다.

---

## 4. 매장 Wi-Fi 단절 시 동작 상태

* **오프라인 캐시 보장**: 인터넷이 끊겨도 이전에 저장된 로컬 캐시(`content.json`)를 사용하므로 고객의 고기 부위 설명 기능은 정상 작동합니다.
* **네트워크 복구 시 자동 동기화**: Wi-Fi가 재연결되면 백그라운드 리스너가 즉시 최신 콘텐츠 버전을 감지하여 자동 동기화합니다.
