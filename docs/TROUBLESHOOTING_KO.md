# 문제 해결 가이드 (한국어)

## 1. 캐릭터가 화면에 나타나지 않는 경우
1. **다른 앱 위에 표시 권한**: `설정` → `애플리케이션` → `특별한 접근 권한` → `다른 앱 위에 표시`에서 `고기 부위 안내`가 켜져 있는지 확인합니다.
2. **다시 표시**: 앱 아이콘을 눌러 직원용 관리 대시보드를 열고 `[캐릭터 화면에 다시 표시]`를 누릅니다.
3. **상주 알림**: 알림 바에 "고기 부위 안내가 실행 중입니다."가 있는지 확인합니다.

---

## 2. 키오스크 서버 연결 끊김이 감지되지 않는 경우
1. **접근성 서비스**: `설정` → `접근성` → `설치된 서비스` → `고기 부위 안내`가 켜져 있는지 확인합니다.
2. **감시 앱 선택**: 설정 마법사에서 실제 매장 키오스크 앱을 선택했는지 확인합니다(기본값은 테스트 키오스크).
3. **5분 쿨다운**: 같은 오류가 화면에 계속 떠 있으면 5분에 한 번만 안내창을 띄웁니다.
4. **오류 문구 차이**: 앱은 다음 문구만 감지합니다.
   * 서버에 접속이 끊겼습니다
   * 서버 접속이 원활하지 않습니다
   * 네트워크 연결을 확인해주세요
   * 통신 연결 오류

   매장 키오스크의 문구가 다르면 앱 코드(`KioskErrorAccessibilityService`)에 추가하고 앱 업데이트를 배포해야 합니다. 관리자 웹에서는 바꿀 수 없습니다.
5. **동작 확인**: 직원용 대시보드의 `[테스트 오류창 띄우기]`로 안내창 표시를 확인할 수 있습니다.

---

## 3. "전원 메뉴 열기"가 동작하지 않는 경우
전원 메뉴는 접근성 서비스를 통해 엽니다. 접근성 서비스가 꺼져 있으면 안내 메시지만 나오므로, 2-1 항목을 확인하거나 태블릿 측면 전원 버튼을 길게 눌러 재시작합니다.

---

## 4. 태블릿 재부팅 후 자동 실행이 되지 않는 경우
* **삼성 갤럭시 탭**: `설정` → `배터리 및 디바이스 케어` → `배터리` → `백그라운드 사용 제한`에서 `고기 부위 안내`를 절전 예외 앱에 추가합니다.
* **레노버**: `설정` → `앱 관리` → `자동 시작 관리자`에서 허용합니다.
* **샤오미 등**: `보안` 앱 → `자동 시작` 허용, 배터리 세이버 `제한 없음`.
* 앱을 설정 화면에서 **강제 중지**하면 Android가 자동 실행을 막으므로, 앱을 한 번 직접 실행해야 합니다.

---

## 5. 새 포스터가 태블릿에 안 보이는 경우
* 태블릿은 포스터를 모두 받은 뒤에 새 버전으로 바뀝니다. 다운로드가 실패하면 30초부터 최대 10분 간격으로 자동 재시도합니다.
* 직원용 대시보드의 `[수동 콘텐츠 동기화]`로 즉시 다시 받을 수 있습니다. "동기화 실패"가 나오면 매장 Wi-Fi를 확인하세요.

---

## 6. 매장 Wi-Fi가 끊겼을 때
* 마지막으로 받은 포스터와 설정으로 정상 동작합니다.
* Wi-Fi가 다시 연결되면 실시간 리스너가 최신 설정을 받아 자동으로 반영합니다.
