# 관리자 웹 콘솔 사용 설명서 (한국어)

## 1. 개요
관리자 웹은 매장의 모든 태블릿에 표시되는 포스터 이미지, 말풍선 문구, 팝업 자동 닫힘 시간을 한 곳에서 바꾸고, 태블릿 상태를 확인하는 화면입니다.

---

## 2. 접속 방법
* 운영 주소: `https://meatguideoverlay.web.app` — 접속하면 아이디·비밀번호 없이 자동으로 관리자 화면이 열립니다.
* 로컬 개발: `cd admin-web && npm run dev` 후 `http://localhost:5173`

> [!WARNING]
> 비밀번호 없는 방식이므로 사이트에 접속할 수 있는 사람은 누구나 설정을 바꿀 수 있습니다. 자세한 내용은 [보안 문서](SECURITY.md)를 참고하세요.

서버에서 현재 설정을 불러오지 못하면 빨간 안내가 표시되고 [적용] 버튼이 동작하지 않습니다. 잘못된 기본값으로 기존 설정을 덮어쓰지 않기 위한 동작이므로, 네트워크를 확인한 뒤 새로고침하세요.

---

## 3. 화면 구성

### 3.1 연결된 태블릿 현황
각 태블릿의 이름, 설치된 앱 버전, 콘텐츠 버전, 온라인/오프라인, 모델, Android 버전, 마지막 보고 시간, `최신 앱`/`업데이트 필요` 상태를 보여 줍니다. 마지막 보고가 10분을 넘으면 오프라인으로 표시됩니다.

### 3.2 말풍선 문구 (다국어)
* 한국어 문구를 입력하면 영어·일본어가 자동 번역됩니다. 번역 결과는 직접 고칠 수 있습니다.
* 자동 번역이 실패하면 `Guide: …`처럼 한국어가 그대로 들어가므로, 적용 전에 영어·일본어 칸을 꼭 확인하세요.

### 3.3 팝업 포스터 이미지 (한국어 / English / 日本語)
* 언어 탭을 고른 뒤 PNG·JPG·WebP(25MB 이하) 이미지를 올립니다.
* 올리지 않은 언어는 기존 이미지를 유지합니다.
* 태블릿은 너무 큰 이미지를 메모리에 맞게 줄여서 표시합니다. 가로 3000~4000px 정도면 충분합니다.

### 3.4 태블릿 전원 관리
* **매일 자동 재부팅**: 안전을 위해 사용 중지되어 있습니다(앱 v1.0.17부터).
* **팝업 무터치 자동 닫힘**: 분 단위로 설정합니다. `0`은 자동 닫힘을 사용하지 않습니다. 기본 5분입니다.
* 화면 절전 시간 설정은 없습니다. 태블릿은 영업 중 항상 켜져 있고, 영업 종료 후 직원이 화면을 끕니다.
* 캐릭터 위치는 모든 태블릿에서 좌측 상단으로 고정됩니다.

### 3.5 적용
**[다국어 및 태블릿 전원/절전 설정 일괄 적용]**을 누르면 버전이 1 올라가고, 온라인 태블릿에 바로 반영됩니다. 새 포스터는 태블릿이 내려받은 뒤에 표시되며, 실패하면 태블릿이 자동으로 다시 받습니다.

### 3.6 태블릿 미리보기
오른쪽 미리보기에서 캐릭터, 말풍선, 포스터 팝업을 실제 태블릿처럼 확인할 수 있습니다.

> 게시 이력 복원, 돼지고기·소생갈비살 메뉴 편집, 오류 감지 문구 편집 기능은 현재 관리자 웹에 없습니다.
