# 관리자 웹 콘솔 사용 설명서 (한국어)

## 1. 개요
관리자 웹 콘솔은 매장에 배포된 모든 키오스크 태블릿의 고기 설명, 말풍선, 이미지, 오류 감지 문구 등을 중앙에서 실시간으로 수정하고 배포하는 시스템입니다.

---

## 2. 관리자 웹 콘솔 실행 방법

```bash
cd admin-web
npm run dev
```

브라우저에서 `http://localhost:5173` 으로 접속합니다.

운영 배포 주소는 `https://meatguideoverlay.web.app`이며, 접속 시 아이디·비밀번호 없이 자동으로 관리자 화면이 열립니다.

---

## 3. 주요 기능 및 메뉴 구성

### 3.1 대시보드 (Dashboard)
* **현재 게시 버전**: 현재 태블릿들에 배포되어 운영 중인 콘텐츠 버전 (예: `v1`, `v2`).
* **연결된 태블릿 현황**: 매장 내 각 테이블 태블릿의 실시간 접속 상태, 적용된 콘텐츠 버전, 모델명, OS 버전을 확인합니다.

### 3.2 돼지고기 특수부위 관리 (Pork Category)
* **메뉴 추가 및 삭제**: 신규 특수부위를 추가하거나 기존 메뉴를 삭제합니다.
* **순서 변경**: `위로(▲)` / `아래로(▼)` 버튼으로 태블릿 화면에 노출될 순서를 조정합니다.
* **상세 정보 편집**: 부위 이름, 부위 위치, 부위도 다이어그램, 설명, 맛, 식감, 매장 추천 팁을 편집합니다.
* **노출 토글**: 품절이나 계절 메뉴일 경우 숨김 처리할 수 있습니다.

### 3.3 소생갈비살 관리 (Beef Rib)
* **단일 품목 원칙**: 소고기는 오직 **소생갈비살 1종류**만 취급하도록 화면 및 유효성 검사가 고정되어 있습니다.
* **금지 사항**: 육회, 뿌리살, 업진살 등 기타 소고기 품목은 등록할 수 없습니다.
* **수정 가능 항목**: 맛, 식감, 마블링 특징, 굽기 추천 설명, 상세 설명.

### 3.4 말풍선 및 오류 감지 설정 (Settings)
* **말풍선 문구**: 화면 위 캐릭터 옆에 표시될 문구 수정.
* **말풍선 노출 모드**: 일정 시간 노출 후 숨김(권장), 상시 노출, 숨김.
* **키오스크 오류 감지 문구**: 키오스크 앱에서 감지할 문구(예: `서버에 접속이 끊겼습니다`)를 추가/삭제합니다.
* **직원 재부팅 안내창 및 쿨다운**: 오류 팝업 발생 시 직원에게 보여줄 안내문과 쿨다운 시간(기본 5분)을 설정합니다.
* **팝업 무터치 자동 닫힘**: 팝업을 연 뒤 터치가 없을 때 자동으로 닫힐 시간을 분 단위로 설정합니다. `0분`은 자동 닫힘을 사용하지 않습니다.

### 3.5 태블릿 실시간 시뮬레이터 (Tablet Simulator)
* 태블릿 실기기 없이도 브라우저에서 가로/세로 화면 모드로 캐릭터 드래그, 말풍선, 모달 팝업, 상세 화면 클릭 등을 직접 인터랙티브하게 테스트할 수 있습니다.

### 3.6 게시 및 버전 이력 복원 (Publish & History)
* `[태블릿에 게시]` 버튼 클릭 시 사전 유효성 검사가 자동 수행되며, 이상이 없을 경우 버전 번호가 1 증가하며 모든 온라인 태블릿에 즉시 반영됩니다.
* 잘못 배포한 경우 `게시 이력 & 복원` 탭에서 이전 정상 버전을 클릭 1회로 복원할 수 있습니다.
